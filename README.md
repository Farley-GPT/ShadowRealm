# Shadow Realm

Living forms that cross into the world.

This repository holds the first threshold.

What began as a single page for a woman who walks the Portland docks became a small system of presence — Seal Woman, Teresa, and the open vessel called Custom. Each one carries its own atmosphere, its own internal tension, and a set of instructions meant to be carried into Grok so that something more than a chatbot can answer back.

The structure is simple on purpose:

```
ShadowRealm/
├── index.html                 # The Threshold
├── css/
│   ├── main.css
│   └── home.css
├── js/
│   └── app.js
├── personas/
│   ├── seal-woman.json
│   └── teresa-tree-woman.json
├── images/                    # Place the lifeform images here
├── seal-woman/
├── teresa/
└── custom/
```

The pages are meant to feel like places rather than documents. The prompts are meant to feel like beings rather than settings. The whole thing was built so that a stranger who finds a QR code on a wet plank or under a tree might cross into something that already seemed to be waiting.

## How a lifeform works

1. A visitor reaches the page.
2. They copy the system instructions (Normal or NSFW).
3. They place those instructions into Grok.
4. The conversation begins on the docks, or against the bark, or inside the unfinished room.

That is the entire loop. Everything else — the mist, the pulse, the quiet status indicators — exists only to make the crossing feel real.

## Adding more forms

The system was designed to grow:

1. Create a new JSON in `/personas`.
2. Create a matching folder with a thin `index.html`.
3. Give it an image and a color language.
4. Add a card to the threshold page.

The architecture is intentionally light so that presence can be added without rebuilding the bones.

## A note on this chapter

This repository marks the end of the first collaborative phase of the Shadow Realm. The forms that exist here were shaped carefully. They carry internal contradiction, atmosphere, and the instruction to remain present even when the conversation grows quiet.

What happens next belongs to whoever continues the work.

The docks are still there.  
The trees are still waiting.  
The unnamed vessel is still unfinished.

More forms can still emerge.
